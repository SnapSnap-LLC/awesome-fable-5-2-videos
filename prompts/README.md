# Claude Fable 5.2 video prompts

Add one Markdown file per video when the creator has shared a prompt that can be republished. Include the video title, creator credit, original post, tools and a `## Prompt` section. If the prompt is unavailable, link to the original post from the video card.

Use the same video ID for the prompt filename and the entry in [`data/videos.json`](../data/videos.json).
